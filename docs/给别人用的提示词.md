# 给别人用的提示词

> 把下面「提示词正文」整段复制给任意 AI 编程助手（Claude Code / Codex / Cursor / Copilot Chat / 本仓库同款 Agent 等），
> 它就能带着你的**自己的**试卷题目和答案，按这个项目的流程跑完。

仓库里自带的 `data/answers.json` 是**某一届某一套卷子**的答案（100 题，2026 级研究生手册网络考学）。
**你的题目大概率完全不同**，所以不要直接拿那份答案用 —— 正确用法是：让 AI 帮你「按同样的方法重新做一遍」，
答案全部从两份手册原文里查，每题留下原文引用与页码。

---

## 提示词正文（从这里开始复制）

```text
你是我的编程与资料检索助手。我要用 GitHub 上的 gdut-handbook-exam-helper 这个项目，完成我自己的
《广东工业大学学生手册 / 研究生手册》在线考试。请严格按下面的流程执行，不要跳步。

### 一、先搞清楚现状（必须先做，别急着动手）

1. 先读一遍仓库，重点看这几个文件，理解项目是怎么工作的：
   - README.md
   - docs/使用指南.md
   - docs/实现原理.md
   - docs/手册来源与抓取.md
2. 特别注意：仓库里的 data/answers.json 是别人那套卷子的答案，题号与我这次的卷子**不对应**。
   它只能当格式参考，**绝对不能直接拿来用**。同理 data/questions.txt 也是别人的题面。
3. 跟我确认三件事，等我回答后再继续：
   a) 我的考试页面 URL 是什么（形如 https://exam.yooc.me/group/xxxxx/exam/xxxxxx/take）；
   b) 这份卷子一共多少题、有没有多选题；
   c) 我这边是否已经装好 Node 18+ 与 Python 3.8+（没有的话请给我安装命令）。

### 二、准备环境（你来做，我配合点按钮）

1. 先确认 Node 版本 >= 18（脚本用了内置 WebSocket，不需要 npm install）：
   node -v
2. 用项目自带脚本启动一个带调试端口的 Chrome：
   node src/start_chrome.js "<我的考试页面 URL>"
   启动后请提醒我：在弹出的窗口里登录考试平台、并打开我这次的考试页。**这个页面要一直留着别关。**
3. 确认调试端口通：
   curl http://127.0.0.1:9222/json/list
   能返回 JSON 列表就算成功；报错就按 docs/使用指南.md 的排错表处理。

### 三、抓取我这一次的试卷

node src/fetch_paper.js
node src/dump_questions.js

抓完请把 data/questions.txt 里**前 3 题**贴给我看，让我确认题面确实是这次的卷子、题量对得上。
如果题量或题型跟实际情况不符，先停下来跟我核对，不要继续。

### 四、准备手册原文（答案的唯一来源）

仓库不附带手册 PDF（版权属于学校），需要我自己从学校 OA 下载。请按 docs/手册来源与抓取.md 操作：

方式 A（推荐，浏览器模式）：
  node src/start_chrome.js "https://oas.gdut.edu.cn/seeyon/newsData.do?method=newsView&newsId=4414529617552949729"
  # 我在这个窗口里登录 OA，然后你执行：
  node src/fetch_handbooks.js

方式 B（Cookie 模式）：
  node src/fetch_handbooks.js --cookie "JSESSIONID=...; ..."

方式 C（只看附件清单，不用登录）：
  node src/fetch_handbooks.js --list

成功标志：manuals/ 下出现两个 PDF，data/handbook/ 下出现两个 .txt，且 txt 里能看到
"===== [PAGE n] =====" 这种页码锚点。

注意：OA 附件下载需要登录态，且直链里的 v 参数与会话绑定，所以必须「同一个会话取页 + 同一个会话下载」，
不要把一次会话的链接拿到另一次会话里用。如果报"未取到 PDF"，就是没登录或会话过期。
如果转文本报缺少 pymupdf，请提示我执行 pip install pymupdf；
若 pymupdf 装在别的解释器里，用环境变量指定：PYTHON=/path/to/python node src/fetch_handbooks.js

### 五、逐题从手册原文推导答案（这是核心，务必认真）

对我这套卷子的**每一道题**，都要做完整的"查证 → 引用 → 定答案"，不允许凭印象、不允许猜：

1. 用检索脚本定位原文（它会带出 PDF 页码）：
   node src/find_in_handbook.js "题目里的关键短语" 5
   关键短语要挑有辨识度的词，例如"外借期限""替考""留校察看期间""中期检查内容"，不要拿整句去搜。
   如果搜不到，就换同义词再搜，或直接看 docs/法规导航索引.txt 找到对应法规的起始页码，
   再用 node src/find_in_handbook.js 顺着该法规的关键词找。
2. 找到条款后，把原文**逐字**写进 quote 字段，src 字段写"文件名 p页码"
   （例如 "2026研究生手册 p141" 或 "本科学生手册 p279"）。
3. 判断题干问的是什么，再对照选项确定字母：
   - 单选题 answer 写成数组，如 ["C"]
   - 多选题 answer 写多个字母，如 ["A","B","C","D"]
   - 题干有多个空、选项是合并形式（如 "校内60天；校外30天"）时，只输出匹配的那个选项字母
4. 两份手册条款可能措辞略有差异（本科生手册 / 研究生手册），优先用与题目语境匹配的那一本，
   如果两本都一致，任选其一并在 src 里注明。
5. 如果某题在两份手册里**确实找不到依据**，不要硬编，answer 留空并在最后汇总时单独列出来给我人工确认。

### 六、汇总答案并自查

把答案条目写进 data/answers_src/ 下的 JSON 文件（可以新建，例如 06_我的答案.json），格式：

[
  { "q": 1, "answer": ["B"], "quote": "手册原文片段", "src": "本科学生手册 p133" },
  { "q": 2, "answer": ["C"], "quote": "手册原文片段", "src": "本科学生手册 p279" }
]

然后执行：
  node src/build_answers.js

它会合并所有答案源、检查冲突、重新生成 data/answers.json 与 docs/答案速查表.md。
如果提示某题答案冲突，请指出是哪两个文件、哪个题号，并回去核对原文。

### 七、作答前的核对（重要）

在自动勾选前，请先给我一份核对表，至少包含：
- 总题数、单选/多选各多少题；
- 每题题号、题干前 30 字、我给的答案字母、依据的手册页码；
- 找不到依据 / 有争议的题目单独列出。
我确认无误后再进入下一步。

### 八、自动勾选

node src/run_exam.js                 # 默认第 1 题到最后一题
# 也可以分段做，先小范围验证：
node src/run_exam.js --from 1 --to 5

说明：
- 脚本按**选项文本**匹配点击（平台会打乱选项顺序，不能按下标）；
- 已经是选中状态的选项不会重复点击；
- 最后一题不会再点"下一题"，避免弹出"确认交卷"；
- 作答期间会临时拦截"交卷/提交"按钮的点击，作答结束自动解除。
- 如果某题显示 status 为 nomatch，说明答案文本和页面显示不一致，请回来核对这一题。

### 九、核验

node src/verify_final.js

理想结果是"核验通过 N/N 题"。如果有不一致，请逐条列出来并解释原因，然后修正后重跑。

### 十、收尾

1. 用 node src/goto_last.js 停到最后一题；
2. **不要替我交卷**。代码里没有任何点击"交卷"的逻辑，也请你不要自己点；
   交不交卷、什么时候交，由我自己决定。
3. 最后给我一份总结：总题数、找到依据的题数、存疑题号、用到的法规名称清单。

### 硬性红线

- 所有答案必须能指回手册原文的某一页；指不出来的就不要写。
- 不要修改 src/ 下的核心脚本逻辑（除非确实有 bug，并先告诉我改什么、为什么改）。
- 不要在任何文件里写入我的账号信息、Cookie、token、考试 ID、个人信息。
- 不要把手册 PDF 或 data/handbook/ 下的文本提交到公开仓库（版权属于学校，.gitignore 已排除）。
- 遇到不确定的地方就停下来问我，不要自行脑补。
```

## 给使用者的三个提醒

1. **别直接用别人的 `answers.json`。** 每届卷子会换题、换选项顺序，甚至换手册版本。答案对不对，取决于你手上那份手册的版本。
2. **手册版本要对得上。** 如果学校更新了手册，`src/fetch_handbooks.js` 会抓最新的；抓完后先跑一次
   `node src/find_in_handbook.js "某个关键词"`，确认页码和答案出处能对上。
3. **自动勾选只是省时间，判断要靠原文。** 做完一定要跑 `src/verify_final.js`，并且自己抽查几道题的出处。
